# StarBoy

StarBoy is an **ESP32-C3-WROOM-02** hardware project for Hack Club.

This repo is set up to document build progress, wiring, and milestones as the board comes together (push buttons, 01x07 OLED/sensor socket, and other modules).

## Project Snapshot

- **MCU:** ESP32-C3-WROOM-02
- **Key hardware so far:**
  - Push buttons
  - 01x07 socket (for OLED + sensor breakout usage)
  - Sensor expansion plans

## How to Use This Repo for Progress Logging

1. Open [`docs/PROGRESS.md`](docs/PROGRESS.md)
2. Add a new dated entry each time you:
   - Solder or wire something
   - Change pin mapping
   - Add/test a component
   - Fix a hardware or firmware issue
3. Include photos, notes, and next steps in each entry
